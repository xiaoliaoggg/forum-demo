欢迎来到自由讨论区

2026-11-17·公告

这是一个完全跑在 GitHub 上的论坛：页面由 GitHub Pages 静态托管，帖子是仓库里的 HTML 文件，讨论和回复存在 GitHub Discussions 里，通过 giscus 嵌在每篇文章底部。

它能做什么

  • 浏览帖子、按分类筛选、站内搜索
  • 用 GitHub 账号在帖子下方评论、回复、点表情
  • 评论自动同步到 Discussions，可被搜索、可被导出
  • 零服务器、零数据库、零月费

它不能做什么

  • 没有站内注册，评论者必须有 GitHub 账号
  • 不能直接在网页里发新帖，新帖需要提交 PR 或去 Discussions 发
  • 没有私信、用户主页、权限组这些重型论坛功能

如果你能接受这三条限制，它就是成本最低的“有个地方讨论”的方案。

评论

评论由 giscus 提供，使用 GitHub 账号登录后即可发言。
