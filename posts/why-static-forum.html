为什么我选择“静态页 + 评论区”而不是真论坛

2026-11-17·闲聊·随笔

Discourse 很强：实时、全文搜索、权限组、邮件通知、插件生态。但它也需要一台至少 2GB 内存的服务器、一个域名、定期的系统更新和备份。对一个十几个人、偶尔聊几句的小圈子来说，这些运维成本远远超过它带来的价值。

静态方案的成本结构完全不同：

  • 托管费：0，Pages 免费额度对文本站绰绰有余
  • 运维：0，没有系统要打补丁，没有数据库要备份
  • 安全性：攻击面几乎只有 GitHub 本身
  • 数据：评论在 Discussions，随时可导出

换来的是三个妥协：必须用 GitHub 账号、发帖要改仓库、没有版块权限。如果这三条对你的社区不致命，那静态方案就是更理性的选择。

论坛的价值在“人”和“内容”，不在“论坛软件”。先有人讨论，再考虑要不要升级到 Discourse。
